# directory, every file under it mapped. scripts/sync-from-drivine4j.sh merges drivine4j's changes to these into the module.
# Module files with no drivine4j source (api/, json/, number/, text/, time/, the platform source sets) are the module's own.
# So are store/, the part of drivine4j's OracleSql, SqliteSql, SqliteCypherValues, SqliteFunctions, SqliteTimestamps,
# Stamps and LowerCopies that the compiler calls, and CompilerException, which drivine4j's DrivineException stands for in
# its copy: drivine4j keeps those files and calls store/, and scripts/port-rewrites.sed renames them in what it merges.
